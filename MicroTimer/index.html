Questions

What is the 25-minute option for?

It's the classic Pomodoro focus session: work for 25 minutes, then take a short break.

Will the countdown beep if my screen is locked?

Phones don't let web pages make sounds while locked, so it beeps as soon as you unlock. Keep the screen on if you need to hear it straight away.

Does it keep time if I leave the page?

Yes. MicroTimer remembers when it started, so the time is right when you come back.
